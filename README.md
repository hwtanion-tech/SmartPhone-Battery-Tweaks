# SmartPhone Battery Tweaks

为 **SmartPhone Alpha 0.3.91.1** 提供可视化、可独立控制的电量优化补丁。

## 安装与操作

1. 保留并启用 SmartPhone Alpha **0.3.91.1**。
2. 移除旧版电量补丁，导入 `dist/SmartPhone-Battery-Tweaks-1.1.0.mod.zip`。
3. 启用补丁，**完整刷新游戏**（不仅是读档）。不要同时启用两个版本。
4. 在 **游戏设置 → 万能的智能手机模组设置** 或 **手机 → 系统设置** 调整。
5. 点击 **保存并应用**，立即生效，无需重载。

手机没电时仍可通过游戏设置调整。配置保存失败会显示警告，不会假装已持久化。

## 功能

| 设置 | 默认 | 原版（0.3.91.1） |
| --- | --- | --- |
| 自然耗电 | 关闭 | 0.3 点/游戏分钟 |
| 手机打开、关闭 | 免费 | 1 点/次 |
| 应用切换 | 免费 | 0.2 点/次 |
| 拍照耗电 | 5 点/次 | 30 点/次 |
| 场所充电 | 2000 点/游戏小时 | 500 点/游戏小时 |
| 过充保护 | 开启 | 过充达到阈值后按 0.01 系数损耗 |

- 支持总开关、独立开关和数值输入；自然耗电 `0–100`、拍照 `0–10000`、充电 `0–100000`，支持小数。
- **保存并应用**：保存当前输入；**恢复 mod 默认**：恢复上表默认；**恢复原版参数**：立即恢复本补丁加载时捕获的参数与操作费用。
- 关闭总开关会恢复加载时参数，但保留自定义值备用。启用开关也需点击保存。
- 显示手机电量与最大容量；数值单位是**点数，不是百分比**。
- 按操作上下文控制费用，不再把所有 `1`、`0.2` 点扣电直接免单；拍照和自然耗电使用这些数值也能正确扣电。
- 免费操作仍执行原版电量检查，保留低电量提醒、损坏及关机判定。

### 保留的游戏机制

不直接修改当前电量、手机型号、最大容量或存档结构。不自动充满或修复。
拍照次数限制、充电时被盗风险以及**电量耗尽关机损失 50 点最大容量**均保留。
过充保护只防止过充损耗，不防止其他损坏。

场所给充电宝补电也使用场所充电速度，原版 5 倍系数保留（默认变为 10000 点/游戏小时）。
充电宝**向手机供电**速度未修改，仍为原版 5 点/游戏分钟。
充电速度设为 0 会暂停场所充电，但不暂停充电宝向手机供电。
速度在原版结算时读取，修改会影响尚未结算的整个充电时段，建议先取回设备再调整。

### 配置范围与卸载

配置写入当前浏览器、当前站点的 `localStorage`，键为 `SmartPhoneBatteryTweaks.settings.v1`。
**跨存档共用，不随存档导出**；更换站点、浏览器或清除站点数据可能丢失。
不向存档增加字段，不迁移旧存档。坏配置使用默认值并提示，直到用户保存前不会覆盖坏记录。
卸载时禁用并移除补丁，完整刷新游戏。旧配置保留；已发生的电量或容量变化不回滚。

## 兼容范围

- ModLoader `>=2.31.2`、DoL `>=0.5.12.13`（以 0.5.12.13 导出代码为参考；更高版本未实机验证）。
- SmartPhone Alpha **严格依赖 0.3.91.1**，不承诺其他版本兼容。
- 不额外依赖 TweeReplacer，不覆盖手机主 MOD 或整段游戏 passage。
- 不应同时运行其他覆盖相同电量参数/函数的补丁。
- 本项目仅包含电量补丁源码，不包含游戏导出数据、游戏素材或手机主 MOD 源码。

## 开发

需要 Node.js >=20、Python >=3.9；没有 npm 第三方依赖。

```sh
npm run check
npm test
npm run build
```

构建只读取 `src/boot.json` 列出的项目文件，生成可重复构建的 ModLoader ZIP，并校验 CRC。
原有 `SmartPhone-Battery-Tweaks-1.0.0.mod.zip` 保留在本地，不纳入 Git。

```text
src/boot.json                 ModLoader 清单
src/scripts/battery-tweaks.js  参数、操作上下文、持久化、设置界面
src/styles/battery-tweaks.css  仅作用于本补丁的样式
tests/                       自动化测试
tools/build.py               无第三方依赖的构建脚本
docs/                        架构与人工验收说明
dist/                        构建产物（Git 忽略）
```

控制台 API：`window.SmartPhoneBatteryTweaks`，提供 `getSettings()`、`update({...})`、`resetDefaults()`、`resetVanilla()`、`getStatus()`。
`update()` 对非法值拒绝整次更新；返回 `{ settings, persisted }`，`persisted: false` 表示只在本次运行生效。

测试覆盖与尚未完成的实机验收见 [docs/TESTING.md](docs/TESTING.md)。
