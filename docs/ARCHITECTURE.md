# 实现说明

## 初始化

检测手机 API 与参数，捕获原始数值，读取带 schemaVersion 的独立 localStorage 配置。
拒绝与 1.0.0 包装同时安装；重复执行 1.1.0 不再包装。
ModLoader 清单负责加载顺序与严格手机版本约束，脚本另做 API/数值检查。

## 费用归属

不按数值全局免单。包装 `togglePhone` 与 `toggleApp`，建立同步调用上下文栈。
仅上下文中第一笔预期费用归属当前操作，之后再发生的拍照扣电不受该免费开关影响。
嵌套应用切换有自己的上下文；`finally` 确保正常返回及异常时清理栈。
`PhonePowerPass` 使用非免费上下文屏蔽外层操作，避免自然耗电与操作费用相同导致误判。
免费时仍调用原 `PhoneConsumption(0)`，保留所有原版检查，不复制手机主 MOD 函数。
此适配基于 0.3.91.1 的调用顺序；若上游版本改变为异步扣电或增加前置扣电，需重新适配。

## 设置与恢复

四个全局数值在初始化、保存、恢复时更新。总开关关闭时使用捕获值。
恢复预设不强制改写手机电量、容量、充电开始时间或游戏时间。
场所充电在原版结算时读取当前速度，因此修改速度会影响**尚未结算的整个充电时间段**；建议取回充电设备后再改速度。
localStorage 失败时配置仍可在内存生效，API 与界面均明确报告失败。
保存时严格验证全部传入字段，非法配置不产生部分更新。

## 界面

使用原生 DOM 与带命名空间的 CSS，不替换原版 widget。
MutationObserver 监听异步渲染的设置区域，下一帧去重挂载。
只修改 `.spbt-panel` 内部；忽略面板内部 mutation，避免自触发循环。
原版设置网格通过手机标题定位，手机内部通过 `#phone-content` 的系统设置标题定位。
中文当前导出环境与英文 System Settings 标题适配，其他语言需补充标题定位。
状态在扣电、时间推进和页面变化后刷新；不轮询、不写入存档。
保存或恢复预设会刷新所有已挂载面板，未保存输入由最新配置替换。
