# 测试与验收

## 自动化

```sh
npm run check
npm test
npm run build
```

Node 内置测试覆盖默认参数、操作独立开关、0/0.2/1/5/30 点拍照、嵌套调用、自然耗电、异常清理、原版检查、耗尽关机、预设、总开关、配置校验、持久化失败、坏配置、重复安装及依赖检测。
独立编写的行为夹具不包含游戏代码。

可选：对本地原版导出 ZIP 中的函数进行内存集成测试：

```powershell
$env:SPBT_EXPORT_PATH = '你的游戏导出数据.zip的绝对路径'
npm test
```

测试通过 Python 只读提取指定手机函数，在 Node vm 中执行，不写出或上传游戏代码。
CI 没有导出数据，此组测试会明确标记跳过。

## 浏览器演示

`demo/index.html` 是独立编写的手机 API 夹具，用于验证真实 DOM 渲染、输入、保存和窄屏布局，**不是实际游戏**。
项目根目录运行 `python -m http.server 8765 --bind 127.0.0.1`，打开 `http://127.0.0.1:8765/demo/`。
演示与实际游戏 origin 不同，设置互不影响。可通过“模拟手机操作／拍照／推进时间”观察。
在演示页控制台运行 `await runBatterySmokeTests()`，可重复执行真实 DOM 冒烟测试；结束后恢复原演示设置和电量。

## 实际游戏人工验收（发布前仍建议执行）

- [ ] 移除 1.0.0，导入新包，完整刷新；确认控制台启用日志无错误。
- [ ] 游戏设置与手机系统设置均出现面板；反复开关、切换页面不重复挂载。
- [ ] 手机没电时仍能进入游戏设置；面板不自动充电或修复容量。
- [ ] 每个独立开关与总开关正确生效，保存后刷新仍保留。
- [ ] 拍照设为 1、0.2 时仍扣电；设为 0 时不扣电。
- [ ] 免费操作仍提示低电量，拍照耗尽后仍关机并损失 50 点容量。
- [ ] 场所充电与过充保护正确；充电宝供电速度不变。
- [ ] 两种预设能恢复，已发生的存档数值不回滚。
- [ ] 亮色/暗色主题、手机缩放与窄屏布局无明显溢出。
- [ ] 存档读写、手机闹钟、拍照任务、应用跳转无回归。

**注意**：场所充电在原版结算时读取当前充电速度，修改会影响尚未结算的整个时间段；建议先取回充电设备再改。
